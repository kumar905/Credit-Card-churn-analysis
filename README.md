# Credit Card Churn Analysis

## Project Overview
This project analyzes customer churn using Python and identifies the key factors that influence customer churn.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Overall Customer Churn Rate
- Churn Rate by Age Group
- Churn Rate by Gender
- Churn Rate by Education
- Churn Rate by Employment Status
- Churn Rate by Monthly Spending
- Churn Rate by Credit Score
- Churn Rate by Card Type
- Churn Rate by Interest Rate
